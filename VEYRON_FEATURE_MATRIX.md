Headless protocol evidence is identified separately from visible/GPU runtime evidence.

| State | Meaning |
|---|---|
| IMPLEMENTED | Code is integrated and the stated behavior has direct test or runtime evidence. |

| UNVERIFIED | Existing code cannot be judged from available evidence. |
